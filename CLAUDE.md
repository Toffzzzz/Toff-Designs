# Toff Studio portfolio: instructions for every session

This is the Toff Studio portfolio site: plain HTML, CSS and JavaScript, to be hosted on GitHub Pages. It is built in rounds. Each round's full prompt is saved in `rounds/`.

## Before changing anything

1. Read **DESIGN.md** (exact design values), **DECISIONS.md** (dated log of every design decision) and **CHECKLIST.md** (quality checks).
2. Check the request against DECISIONS.md. If it contradicts an earlier decision, warn the owner before acting.
3. Every new decision the owner makes goes into DECISIONS.md as a new dated line. Never remove old lines; if a decision changes, add a line saying what it replaces.
4. Whenever a value changes in `settings.js` or DESIGN.md, update the other so they match.
5. At the end of every round, run every item in CHECKLIST.md. When the owner reports a bug, add a check that would have caught it.
6. Save each round's prompt as `rounds/round-NN.md`.

## Standing rules

- Never delete, move, rename or overwrite anything in the Everest project folder, the bluebird-wellness folder, or anywhere outside this project folder, except files a round explicitly says to create or update in `~/.claude/`. Treat everything else on the Mac as read-only.
- Never delete files inside `assets/`. Copied or processed files go in their own subfolders.
- If any step would delete or overwrite something, stop and tell the owner first.

## The concept

One continuous ink line runs through the entire page, like a single pen that never lifts. It writes four phrases, flows into drawings of the studio's website styles, and ends with a chat box where the visitor says what they need. Everything is driven by scrolling.

## Global look

- Background: warm off-white #F7F5F0. Line: deep ink navy #1F3A5F. The same stroke thickness throughout, with round ends and joins.
- Every drawn line has a shadow: a copy in soft grey, about 2–3px below, slightly blurred and semi-transparent, drawn a tiny moment behind the main line, so it looks like natural ink on paper. Subtle and realistic, never like a duplicate line.
- A small studio name mark top left ("Toff Studio" for now), always visible and unobtrusive.
- Calm, spacious, premium. Lots of empty space.

## Global motion rules (every section)

- Laptops/desktops: animations are driven by scrolling, at a smooth, natural speed, never rushed, starting only when that part is on screen.
- Phones: each part plays by itself when it comes into view, at a natural speed.
- Once something has drawn or played, it never reverses or replays when scrolling back up; it stays on its final state. Coming back to the page from another page may reset it.
- Scrolling is continuous everywhere EXCEPT the finale (Section 5), which may pin briefly while it plays. Keep that one pin smooth.
- The page always opens at the very top.
- If the visitor has "reduce motion" turned on, show every section finished, with no animation.

## Settings

Every adjustable value lives in one file, `settings.js`: studio name, colours, stroke width, shadow offset/blur/opacity, the font for each phrase, drawing speeds, section order, which style sections are shown, links, email, and whether the chat box is live or demo. The owner must be able to change any of these without touching other code. Never hard-code one of these values anywhere else.

## How the site is built (short version; README.md has the detail)

- `script.js` lays everything out on one timeline and runs a single pen clock: scroll-driven on laptops, self-playing on phones, never backwards.
- Phrases are drawn from single-line fonts in `paths/fonts/` (generated by `tools/build-fonts.mjs` from `tools/svg-fonts/`). Never animate font outlines.
- Style drawings are single-stroke SVGs (`assets/face-line.svg` format: a path whose id ends in `-main` enters at the top centre and leaves at the bottom centre; other paths have `data-y`). Never redraw or retrace `face-line.svg`.
- The Everest AC animation (`js/everest-ac.js`) is a faithful copy of the Everest site's code. Don't "improve" it; changes there must stay faithful to the original.
- Preview locally with `python3 tools/serve.py 8000`.
